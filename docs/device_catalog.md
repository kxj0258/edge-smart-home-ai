## 场景

- 回家：开灯、开窗帘、客厅摄像头进入隐私模式、查询网络。
- 离家：关闭媒体/照明/空调、关窗帘、退出客厅摄像头隐私模式、门口录像。
- 观影：打开电视和机顶盒、进入 IPTV、关窗帘和灯。
- 睡眠：关闭客厅媒体/照明、关窗帘、打开卧室净化器、启用客厅监控。
- 起床：打开卧室灯和窗帘，关闭卧室净化器。
- 用餐：打开厨房灯和客厅灯，关闭客厅窗帘。
- 夜灯：客厅和卧室亮度设为 20%，关闭两处窗帘。
- 节能：关闭媒体、空调、风扇和智能插座。
- 安防：锁定入户门、关闭摄像头隐私模式并开始门口录像，需高风险确认。

场景由配置展开为标准 `DeviceCommand`。各子命令独立执行并返回结果；Mock
backend 不提供事务回滚，因此场景可能部分成功。

Agent 生成的多设备 plan 同样不声称事务回滚，但在首个副作用之前会完成整个
plan 的 device/action/参数和 Safety 预检。

## 安全边界

- 查询、显示摄像头画面为低风险。
- 摄像头隐私/录像和访客 Wi-Fi 为中风险，必须保留审计记录。
- 重启网关为高风险，文本 CLI 要求显式确认；语音入口不会自动确认。
- 门锁锁定/解锁属于高风险动作，离家和安防场景必须先确认；不实现医疗诊断或真实报警联动。
