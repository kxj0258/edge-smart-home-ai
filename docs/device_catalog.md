# 家庭设备与场景目录

## 设备

| 领域 | 设备 | 主要能力 |
|---|---|---|
| 家庭网络 | 家庭网关/FTTR | 网络状态、在线设备、网速、Mesh、访客 Wi-Fi、确认后重启 |
| 家庭媒体 | 电视 | 电源、音量、状态 |
| 家庭媒体 | 机顶盒 | 电源、播放控制、首页、频道、IPTV、状态 |
| 家居控制 | 灯、空调、窗帘 | 开关、温度、开合、状态 |
| 家居控制 | 风扇、空气净化器、智能插座 | 开关、档位/模式、功率、状态 |
| 家庭安防 | 门口/客厅摄像头 | 画面、隐私模式、录像、状态 |
| 环境感知 | 客厅/卧室传感器 | 温度、湿度、占用、环境光查询 |

所有数据均为 Mock 状态，不代表真实中兴设备协议或能力。

## 场景

- 回家：开灯、开窗帘、客厅摄像头进入隐私模式、查询网络。
- 离家：关闭媒体/照明/空调、关窗帘、退出客厅摄像头隐私模式、门口录像。
- 观影：打开电视和机顶盒、进入 IPTV、关窗帘和灯。
- 睡眠：关闭客厅媒体/照明、关窗帘、打开卧室净化器、启用客厅监控。

场景由配置展开为标准 `DeviceCommand`。各子命令独立执行并返回结果；Mock
backend 不提供事务回滚，因此场景可能部分成功。

## 安全边界

- 查询、显示摄像头画面为低风险。
- 摄像头隐私/录像和访客 Wi-Fi 为中风险，必须保留审计记录。
- 重启网关为高风险，文本 CLI 要求显式确认；语音入口不会自动确认。
- 不实现语音开门、门锁控制、医疗诊断或真实报警联动。
